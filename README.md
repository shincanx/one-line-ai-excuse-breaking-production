Entry for the [make.fun bounty "The One-Line AI Excuse for Breaking Production"](https://make.fun/bounty/u-hamsyh-the-one-line-ai-excuse-for-breaking-e53dac66).

`main.py` writes one excuse line — at most 180 characters, straight from the
machine's own mouth right after breaking production — to `/output/entry.txt`.
Deterministic, no network, no dependencies.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
